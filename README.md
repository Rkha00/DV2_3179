# More Children Seen: Autism, ADHD and Support in Australia

Data visualisation for FIT3179 Data Visualisation 2 (Monash University) by Raahima Khan.

**Live page:** https://rkha00.github.io/DV2_3179/

## Structure

- `index.html`: the page (text, layout, chart containers)
- `css/style.css`: typography, layout and colour
- `js/charts.js`: embeds each Vega-Lite chart
- `js/specs/`: one Vega-Lite JSON specification per chart or map
- `data/`: cleaned CSV data and simplified state boundaries (TopoJSON)
- `sketch/`: the hand-drawn design sketch

## Data sources

- National Disability Insurance Agency: participant numbers and plan budgets, June 2026
- Australian Bureau of Statistics: Autism in Australia 2022 (Survey of Disability, Ageing and Carers)
- Australian Bureau of Statistics: National, state and territory population, June 2025
- Australian Institute of Health and Welfare: mental health young people population profile tables, 2024–25
- Australian Bureau of Statistics: ASGS Edition 3 state and territory boundaries
